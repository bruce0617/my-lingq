# My LingQ

LingQ처럼 영어를 공부하는 개인용 웹앱. 유튜브 영상·기사·텍스트를 레슨으로 만들어 읽고, 모르는 단어와 구문을 저장하고 복습합니다.

**앱 주소:** https://bruce0617.github.io/my-lingq/

## 기능
- 🎬 유튜브 링크 → 자막 자동 가져오기, 영상과 문장 맞춰 재생
- 단어 색 표시(새 단어 파랑 · 학습 중 노랑), 드래그로 구간 해석·저장, 문장 통째로 저장
- 문장 보기, 문장 듣기/느리게 듣기, 번역, 구간 반복, 스크립트 편집
- 단어장, 간격 반복 복습, 학습 통계
- 구글 로그인 → 아이폰·Mac 동기화 (Firebase)

## 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (GitHub Pages로 배포) |
| `apps-script/Code.gs` | 유튜브 자막 서버 (Google Apps Script 웹 앱) |
| `server.mjs` | 집 Mac용 로컬 서버 (`HOST=0.0.0.0 node server.mjs` → http://localhost:8000) |

## 아이폰에서 앱처럼 쓰기
사파리로 앱 주소 열기 → 공유 버튼 → **홈 화면에 추가** → 구글 로그인.

학습 기록은 Firebase에 본인 구글 계정으로만 저장되며, 이 저장소에는 개인 데이터가 없습니다.
